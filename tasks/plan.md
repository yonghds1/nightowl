# 混合工作区修复实施计划

规格：`docs/superpowers/specs/2026-10-22-mixed-workspace-design.md`（用户已确认）。

1. 用真实临时 Git 子仓和普通目录复现预检、勘察、提交断链。
2. 实现共享的受限目录发现；明确区分非仓库和 Git 故障。
3. 按发现的仓库逐个预检，不改变进程 cwd；保留严格检查与协议。
4. 复用勘察逻辑输出各项目线索，修复根目录提交诊断与推送跳过说明。
5. 同步 plan/run/verify/report 技能、命令模板和中英文 README。
6. 扩展故障、符号链接、路径空格和 CLI 回归，运行 npm run check。
7. 用构建后 CLI 完成混合工作区和纯非 Git 目录实景，审阅 diff 并交付。

限制：不新增依赖、不发布、不修改业务仓库配置、不推送。保留串行原目录执行，无跨仓隔离或版本快照。
